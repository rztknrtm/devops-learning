# Git Notes

## Basic workflow

- git init — initialize repository
- git add — stage changes
- git commit — save changes
- git push — upload commits
- git pull — fetch and integrate changes

## Branches

- git branch — list branches
- git switch -c — create and switch
- git merge — merge branches
- git rebase — replay commits on new base

## Remote repositories

- git remote -v — show remotes
- git fetch — retrieve remote changes
- git clone — copy remote repository

## Undo changes

- git revert — undo commit with new commit
- git reset — move branch pointer

## Other

- git cherry-pick — apply selected commit
- git tag — mark a version
